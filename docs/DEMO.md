# デモ動画の撮影手順

FK Lab の見どころを 60 秒ほどの動画にまとめる手順です。撮影した動画から GIF を作り、README の冒頭に載せます。

## 準備

1. `npm install` のあと `npm run dev` を実行し、表示された URL を Chrome で開く。
2. ウィンドウを 1280 × 720 にする（DevTools のデバイスツールバーで「レスポンシブ」を選び、幅と高さを入れる）。
3. 画面収録を用意する。macOS なら `Cmd + Shift + 5` で「選択部分を収録」を選び、ブラウザの表示領域を囲む。音も入れるなら、収録のオプションでマイクではなくシステムの音を取れる仮想オーディオを選ぶ。
4. 画面上部の「音 入」が有効になっていることを確かめる（最初のキックで音が出る）。

## 撮る場面（合計 約 60 秒）

| 順 | 時間 | 操作 | 見せたいこと |
|---|---|---|---|
| 1 | 0〜8 秒 | お手本「カーブ」のまま「蹴る」 | 壁を巻いて入る。ゴール前後のスロー、ネットの揺れ、歓声 |
| 2 | 8〜18 秒 | 「なぜ曲がった？」パネルを見せる。タイムラインを ×0.25 にして巻き戻し、力ベクトルを見せる | マグヌス力が右へ曲げたことが、矢印と棒グラフで分かる |
| 3 | 18〜26 秒 | 「この軌道を残す」。接触点ピッカーで中心をダブルクリックして「蹴る」 | 同じ向きでも無回転だと曲がらない。軌道を重ねて比べる |
| 4 | 26〜36 秒 | お手本「ナックル」。「揺れ方を変える」を 2 回押して予測線の変化を見せ、「蹴る」。視点を「GK」に | 無回転の揺れ。GK の目線では読みにくいこと |
| 5 | 36〜46 秒 | 「ゴールをクリックして逆算」を押し、球種「カーブ」でゴール右上をクリック。「蹴る」 | 試した軌道が薄い線で重なり、蹴り方が求まる |
| 6 | 46〜56 秒 | 伝説の FK「R・カルロス 1997」を選んで「蹴る」。視点は「真上」 | 壁の外から大きく曲がって入る。パラメータは推定値という表示 |
| 7 | 56〜60 秒 | 「ボールの位置を変える」でピッチをドラッグ | 好きな位置から蹴れる |

## 撮るときの注意

- 判定は蹴るまで分からない。GK に止められたら「揺れ方を変える」でシードを変えるか、GK を「やさしい」にして撮り直す。
- 予測線は、何にも当たらない飛翔だけをゴールラインまで描く。壁や GK に当たるかどうかは予測線には出ない。
- 伝説の FK は、選んだ設定のまま蹴ればゴールになる（設定を変えると結果も変わる）。
- スマホの画面も撮る場合は、DevTools のデバイスツールバーで幅 390 × 高さ 844 にする。

## GIF にする

動画（`demo.mov`）から、README 用の GIF を作る例です。ffmpeg が必要です。

```sh
ffmpeg -i demo.mov -vf "fps=15,scale=720:-1:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse" docs/demo.gif
```

できた `docs/demo.gif` を README の冒頭（「デモ」の節）から参照します。
